# 📦 Inventory Optimization & Sales Insights Dashboard

## 📌 Project Overview
This project focuses on optimizing inventory management using Machine Learning, SQL, and Power BI. It analyzes retail sales data to predict demand and calculate reorder points, helping businesses reduce stockouts and overstocking.

---

## 🎯 Objectives
- Analyze sales trends and product performance  
- Predict product demand using Machine Learning  
- Optimize inventory using reorder point calculation  
- Build an interactive Power BI dashboard  

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn)
- MySQL
- Power BI
- Jupyter Notebook

---

## 📊 Dataset
- Retail sales dataset with ~9800 records  
- Includes product, region, category, and sales details  

---

## ⚙️ Project Workflow
1. Data Cleaning & Preprocessing  
2. Feature Engineering  
3. Exploratory Data Analysis (EDA)  
4. Machine Learning Model (Random Forest)  
5. Demand Prediction  
6. Inventory Reorder Point Calculation  
7. Power BI Dashboard Creation  

---

## 🤖 Machine Learning Model
- Model Used: Random Forest Regressor  
- Goal: Predict product sales (demand)  
- Evaluation Metrics:
  - MAE
  - RMSE
  - R² Score  

---

## 📦 Inventory Optimization
Reorder Point Formula:

Reorder Point = Average Demand × Lead Time

This helps businesses maintain optimal stock levels.

---

## 📊 Dashboard Features
- Total Sales & Orders KPI  
- Sales by Category & Region  
- Monthly Sales Trends  
- Top Performing Products  
- Shipping Performance  
- Inventory Reorder Insights
